# Component scope
dns: bounded UDP relay/filter and inherited upstream TCP retry.
lists: collision-safe flash-resident ESBL and small legacy text overlay.
http: read-only embedded assets and safe diagnostics only.
flash/settings: retained userdata, non-destructive mount, synchronized atomic settings.
netif/events/error: Wi-Fi-only startup and supporting runtime interfaces.
littlefs: vendored wrapper/core with original licenses.
No OTA, update checks, hardware/GPIO or Ethernet components.
